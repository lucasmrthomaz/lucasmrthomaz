## 🎯 Sobre Mim & Proposta de Valor

Sou Engenheiro de Software com **ampla experiência no ciclo completo de desenvolvimento de sistemas**, atuando na concepção de arquiteturas robustas para aplicações **Desktop, Web, Mobile e IoT**. 

Meu diferencial técnico está na **amplitude e profundidade**: domino desde linguagens de baixo nível e escovação de bits perto do *bare metal* (estilo C) até frameworks modernos de alto nível para desenvolvimento ágil de produtos de grande escala.
